YouTube subtitles → Sentence dictation → Progress & stats

Turn listening into active dictation

Ear2Finger is a locally deployable web app that turns YouTube videos into sentence-by-sentence dictation practice: per-word typing, hints, playlists, and a dashboard for your practice history—running on your machine with SQLite, Qdrant, LangChain, and RAG.

1) Overview

Import a YouTube URL → Extract subtitles → Segment into timestamped sentences → Practice with per-word inputs and keyboard shortcuts.

  • YouTube import and subtitle processing (yt-dlp + FFmpeg for audio)
  • Dictation workspace with per-word typing and keyboard shortcuts
  • Session progress tracking (correct / hints / incorrect)
  • Playlists, lesson history, and aggregated stats on the dashboard

Install from source or via pip install ear2finger for a single-process server that serves the API and the built web UI (PyPI package).

2) Installation

• Install from PyPI

The ear2finger package includes the API server and the production web UI. Use a virtual environment, then: 

pip install ear2finger
ear2finger

Open http://127.0.0.1:9528 in your browser.

• Install from source code

You can run Ear2Finger locally for development from the source code:

Backend

cd backend
python -m venv venv
source venv/bin/activate
pip install -e ..
uvicorn ear2finger.app:app --reload --host 0.0.0.0 --port 9528

Shorthand without installing the package: cd backend then uvicorn main:app --reload --port 9528 (shim loads ../src).

Frontend

cd frontend
npm install
npm run dev

Dev UI: http://localhost:9528 — API proxied to port 9528.

3) How to use

  • Open the app in your browser: http://localhost:3000 when using npm run dev, or http://127.0.0.1:9528 when you installed from PyPI and ran ear2finger.
  • Import a YouTube lesson (will extract subtitles, download audio, and build a dictation session).
  • Practice sentence-by-sentence:
    • Use keyboard shortcuts to move between words / sentences
    • Type what you hear; get underline guidance, hints, and looped playback
  • Review your stats on the Dashboard and resume past sessions from Lesson history.

5) AI Coach stack (LangChain + Qdrant + RAG)

Ear2Finger has a lightweight core build (dictation + stats) and a separate full AI build. In the full AI build, the recommendation/coach flow uses a Retrieval-Augmented Generation (RAG) pipeline.

  • Embeddings: lesson text, transcripts, and coach knowledge snippets are converted into vector embeddings.
  • Qdrant: those embeddings are indexed in Qdrant as the vector database for similarity search.
  • LangChain: LangChain orchestrates chunking, embedding calls, vector retrieval, and prompt composition.
  • RAG: when a learner asks for help, the system retrieves relevant context from Qdrant and injects it into the LLM prompt so responses are grounded in lesson content and practice history.

This design keeps the base app fast and simple while enabling a richer AI coach in deployments that provide an LLM API key and vector storage.

6) FAQs

Do I need an AI API key?

Not for this lite build. Core dictation, playlists, and stats work without any LLM provider. A full variant may add coach features that require API keys.

What does “Import” do?

It downloads subtitles for the selected YouTube URL, segments them into sentences, and stores timestamps + practice history for dictation.

Is my practice data stored locally?

By default, data lives in a local SQLite file (configurable via DATABASE_URL). For cloud deployments, point that URL at your hosted database.
